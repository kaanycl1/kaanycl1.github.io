# Kaan Yücel — Personal Portfolio

Static personal portfolio website for Kaan Yücel, focused on AI engineering, LLMs, speech AI, multimodality, knowledge graphs, and MLOps.

## Run locally

Open `index.html` directly in a browser, or serve the directory with any static web server.

Example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy with GitHub Pages

1. Create a repository named `<username>.github.io` or use an existing GitHub Pages repository.
2. Place `index.html`, `style.css`, and `script.js` in the repository root.
3. Enable GitHub Pages from the repository settings.
4. Select the branch containing the site as the deployment source.

## Files

- `index.html` — portfolio content and structure
- `style.css` — responsive styling
- `script.js` — mobile navigation behavior
